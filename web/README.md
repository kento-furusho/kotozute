# web/

`kotozute.app` に置く静的ページ。App Store の審査で URL を求められる。

- `terms.html` … 利用規約
- `privacy.html` … プライバシーポリシー

## 公開する前に埋めるもの

`REPLACE_` で始まる箇所を差し替える。埋めずに公開すると、そのまま表示される。

| 差し替え文字列 | 入れるもの |
|---|---|
| `REPLACE_OPERATOR_NAME` | 運営者名（個人名または屋号） |
| `REPLACE_CONTACT_EMAIL` | 問い合わせ先のメールアドレス |

```bash
grep -rn REPLACE_ web/
```

## 公開先

DNS が Cloudflare にあるので、Cloudflare Pages が素直。
このディレクトリをそのまま配信すれば、以下の URL になる。

- `https://kotozute.app/terms.html`
- `https://kotozute.app/privacy.html`

## 注意

**法律の専門家による確認は受けていない。** 実装の事実に沿って書いた草案なので、
配布前に内容を確認すること。とくに免責は、事業の形（個人／法人）で変わる。

専属的合意管轄の条項は置いていない。Apple の審査で求められるものではなく、
個人向けアプリで運営者の地元を専属管轄にすると消費者に不利とみなされ、
裁判所の判断で移送されることもあるため。必要になったら足す。

内容はコードの実装と対応している。**実装を変えたらここも直す。**
とくに次の3点はアプリ固有の約束なので、食い違うと問題になる。

- ことづてが相手に見える条件（相互ロック）
- オープン済みのことづては編集も取り消しもできないこと
- アカウント削除で相手のことづては消えないこと
