プライバシーポリシー

最終更新日：2026年8月28日

「ことづて」（以下「本アプリ」）は、ふたりで感謝のことづてを書きためて週に一度読み合うためのアプリです。 本アプリでは、広告配信も、行動履歴の解析も、第三者へのデータ提供も行いません。 ここでは、取得する情報と、その使い道を具体的に書きます。

1. 取得する情報

メールアドレスアカウントの識別と、確認コードの送信に使います。
パスワードAmazon Cognito が管理します。当方が内容を知ることはできません。
表示名ペアの相手の画面に表示されます。本名である必要はありません。
ことづての本文と作成日時お客様が書いた内容そのものです。
ペアの設定相手のアカウント識別子、オープンの曜日・時刻・タイムゾーン。
通知用の端末情報通知を許可した場合のみ、Apple から発行される端末トークンを保存します。

本アプリは、位置情報、連絡先、写真、および端末内の他のデータを取得しません。 利用状況の解析ツールや広告用の識別子も使用していません。

2. ことづてが誰に見えるか

お客様が書いたことづては、ペアの相手が読める場合があります。 これは本アプリの目的そのものであり、次の条件をすべて満たしたときに相手の画面へ表示されます。

  • 設定したオープンの日時を過ぎていること
  • 相手も同じ期間に1つ以上ことづてを書いていること

条件を満たすまで、ことづての本文は相手の端末へ送信されません。 また、書いた枚数など、本文以外の情報も相手には表示されません。

ペアの相手以外の利用者が、お客様のことづてを読むことはできません。 当方は、システムの障害対応など必要な範囲を除き、ことづての内容を閲覧しません。

3. 利用目的

  1. 本アプリの提供（ことづての保存・表示、ペアの管理）
  2. 本人確認およびパスワードの再設定
  3. オープンの日のお知らせ（通知を許可した場合）
  4. 障害の調査および不正利用への対応

4. 保存の場所と外部サービス

本アプリのデータは、Amazon Web Services（AWS）の東京リージョン（ap-northeast-1）に保存されます。 サービスの提供にあたり、次の事業者のサービスを利用します。

Amazon Web Servicesアカウント管理、データの保存、メールの送信、通知の中継。
Apple通知の配信（Apple Push Notification service）。

これらは本アプリを動かすための委託であり、お客様の情報を第三者へ販売・提供することはありません。 法令に基づく開示請求があった場合を除きます。

5. 保存期間と削除

情報は、アカウントが存在する間、保存されます。設定画面から次の操作ができます。

ペアの解消 ふたりの関係が終わり、おたがい別の相手を招待できるようになります。 ことづてはどちらの分も消えません。ただし解消より前に書いた分は、以後に組む相手には表示されません。
アカウントの削除 お客様が書いたことづて、アカウント情報、通知用の端末情報を削除します。元に戻すことはできません。 ペアは解消されます。相手が書いたことづては、相手のデータであるため削除されません。

招待リンクの情報は、発行から7日で自動的に失効・削除されます。

6. 通知

通知は、お客様が許可した場合にのみ送信します。 送るのはオープンの日のお知らせのみで、宣伝は送りません。 iPhone の設定からいつでも停止できます。

7. お子様の利用

本アプリは13歳未満の方の利用を想定していません。 未成年の方は、保護者の同意を得たうえでご利用ください。

8. 本ポリシーの変更

内容を変更する場合は、本ページに掲載します。 重要な変更については、アプリ内でお知らせします。

9. お問い合わせ

本ポリシーに関するお問い合わせは support@kotozute.app までご連絡ください。
